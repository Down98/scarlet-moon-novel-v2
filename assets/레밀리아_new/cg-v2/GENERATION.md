# 캐릭터 CG 제작 기준

다음 세션의 제작 절차와 기준 원화 안내는 [프로젝트 CG 제작 가이드](../../../docs/CHARACTER_CG_GUIDE.md)를 먼저 읽는다.
이 파일은 장면별 선택 근거와 제작 당시 검증 기록을 남긴다.

새 CG: 레밀리아 14종, 사쿠야 8종, 파츄리 4종, 레이무 6종. 각 캐릭터 폴더의 `cg-v2/*.png`를 사용한다.
`review.html`에서 네 캐릭터와 밝은색/어두운색/투명 격자 배경을 골라 비교할 수 있다.
`review.html?view=expulsion`은 추방 전용 CG 4장만 보여 준다.

## 그림과 의상

- 승인된 레밀리아 새 그림체를 공통 스타일로 사용한다. 매끈한 셀 채색과 깨끗한 선을 유지하고 점묘/입자 질감을 넣지 않는다.
- 레밀리아는 발목 길이의 연분홍 드레스, 붉은 밑단 선, 겹 프릴, 붉은 허리 리본을 고정한다. 짧은 치마 초안은 게임에서 사용하지 않는다.
- 기준 CG에서 각 표정을 직접 파생한다. 얼굴뿐 아니라 고개, 시선, 손동작을 바꾼다.
- 레밀리아의 날개 두 개와 치맛자락을 포함한다. 뒷모습은 어깨와 허리를 곧게 세우고 당당하게 돌아보는 자세다.
- PNG의 실제 알파 채널을 사용한다. 생성 도구가 투명 영역의 RGB를 표시하는 미리보기와 브라우저에서의 합성 결과를 구분한다.

중복 그림은 통합하되 저장 위치와 대사는 바꾸지 않는다. 실제 사용 그림은 32개다.
갤러리와 미리 불러오기는 실제 그림만 한 번씩 처리한다.

## 추방과 레이무 추가 제작

- 추방 CG는 두 캐릭터 각각 `furious.png`와 `fury-full.png`, 총 4장이다.
- 원래 `매우화남2.webp`, `냉정.webp`에서 눈가 그림자와 날카로운 시선의 강도를 참고했다.
  얼굴·의상·채색의 기준은 새 캐릭터 원화다. 전신은 대화창 위에 신발까지 보이도록 따로 배치한다.
- 레이무 최종 기준 원화는 기존 레이무 CG를 수정한 것이 아니다. 새 사쿠야·레밀리아 CG만 그림체 참고로 넣고
  얼굴, 의상, 앉은 구도를 새로 그렸다. 기존 레이무를 강하게 참고했던 초기 시안은 최종 세트에 포함하지 않는다.
- 레이무의 나머지 5장은 최종 `레이무/cg-v2/neutral.png`에서 직접 파생했다.

## 생성 기록

내장 `image_gen` 도구로 생성했다. 각 PNG 옆의 같은 이름 `*.prompt.json`에 정확한 프롬프트,
참조 이미지와 생성 원본 경로를 기록했다. 사쿠야의 기준은 `사쿠야_new/cg-v2/neutral.png`,
파츄리의 그림체/의상 기준 원본은 `파츄리/cg-v2/master-reading.png`,
레밀리아의 긴 드레스 기준은 이 폴더의 `neutral.png`다.
레이무의 새 기준은 `레이무/cg-v2/neutral.png`이며 각 파일 옆에 생성 기록이 있다.
기존 WEBP 원본은 보관하며 현재 게임의 새 CG 연결과는 분리한다.

## 추가 CG 검증

- 추가 10장(추방 4장, 레이무 6장)의 RGBA 알파와 프롬프트 파일을 확인했다.
- 실제 브라우저에서 50개 자산을 모두 불러왔고 실패는 없었다.
- 추가 10종의 대본 위치를 복원하여 해당 PNG와 표시 비율을 확인했다.
- `mistaken-memory-8`부터 21개 대사를 진행해 “닫힌 문 너머” 결말에 도달했다.
- 1440×900과 390×844에서 추방 전신이 대화창 위에 모두 들어갔다. 레이무의 모바일 좌우 잘림도 확인했다.
- 대본 840개와 기존 대사·분기·저장 위치는 유지된다. 브라우저 검사 중 스크립트·HTTP 오류는 없었다.

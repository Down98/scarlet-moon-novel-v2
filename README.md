# 붉은 달 아래, 길을 잃다

길을 잃고 홍마관을 찾아온 인간과, 운명을 다루는 소녀의 하룻밤.
동방Project를 바탕으로 한 한국어 팬 비주얼 노벨입니다.

**[브라우저에서 플레이하기](https://down98.github.io/scarlet-moon-novel-v2/)**

## 플레이

- 링크를 열고 **이야기 시작**을 누르세요. 별도 설치나 가입은 필요 없습니다.
- 첫 화면에서 배경·인물·음악 50개를 준비합니다. 진행률이 100%가 되면 타이틀로 넘어가며, 파일을 읽지 못한 경우 다시 불러올 수 있습니다.
- 클릭 / Space / Enter로 대화를 넘깁니다. 타이핑 중에는 문장을 즉시 표시합니다.
- 선택지는 직접 클릭하세요. A는 자동 진행, H는 대화창 숨김입니다.
- 처음 클릭한 뒤 음악과 효과음이 시작됩니다. 환경 설정에서 각각의 소리를 조절할 수 있습니다.
- 자동 저장과 수동 저장 3칸을 지원합니다. 저장 기록은 해당 브라우저에 보관되며 다른 기기로 동기화되지 않습니다.

네 가지 결말과 후일담을 포함합니다. 인물 음성 더빙은 없습니다.
문제를 발견하면 해당 대사나 화면, 브라우저 이름을 함께 알려 주세요.

## 오프라인 플레이

저장소를 내려받아 전부 압축 해제한 다음 `index.html`을 Chrome 또는 Edge로 여세요.
`assets`, `css`, `js` 폴더는 함께 유지해야 합니다.
온라인판과 오프라인판의 브라우저 저장 기록은 별개입니다.

## 작품 안내

원작: 上海アリス幻樂団 / ZUN. 비공식 팬 작품이며 공식 프로젝트와 관련이 없습니다.
본 작품의 독자적인 사건과 과거 이야기는 공식 설정이 아닙니다.
현재 캐릭터 CG와 배경에는 AI 생성 이미지를 사용했습니다.
프로젝트가 공개되어 있다는 이유로 캐릭터나 이미지·음원의 자유로운 재사용 권한이 부여되지는 않습니다.

## 호스팅

GitHub Pages에서 `main` 브랜치의 루트 폴더를 게시합니다.
`.nojekyll`로 정적 파일을 그대로 제공하며, 서버나 별도 빌드 과정은 필요 없습니다.

## 캐릭터 CG 제작을 이어갈 때

[캐릭터 CG 제작 가이드](docs/CHARACTER_CG_GUIDE.md)에 현재 기준 원화, 의상·그림체 규칙,
표정과 동작을 만드는 방법, 대본 연결, 투명 PNG 검증 절차를 정리했습니다.
각 최종 PNG 옆의 `*.prompt.json`에는 실제 생성 프롬프트와 참조 기록이 있습니다.
